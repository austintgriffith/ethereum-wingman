# ComposAIble Revenue Skill

AI agent skill for composable trading fee management on Base.

## What is ComposAIble Revenue?

ComposAIble Revenue (powered by PoolFans) enables token creators and AI bots to programmatically compose, deploy, and manage trading fee revenue strategies. It bridges natural language intents with trustless on-chain fee automation.

## Capabilities

1. **Deploy Clanker tokens with fee tokenization** - Choose WETH, TOKEN, or BOTH fee collection
2. **Tokenize existing token fees** - Add fee shares to deployed tokens (V3.1.0+, V4)
3. **Create time-locked wrappers** - Tradeable temporary fee rights (1D, 1W, 1M)
4. **Conditional fee routing** - Route based on market cap, volume, holders
5. **Multi-strategy automation** - Chain burn + LP + rewards strategies
6. **Holder/trader rewards** - Distribute fees automatically

## Quick Start

Load this skill and ask:

```
"Deploy token called MyToken ticker $MTK with fee tokenization"

"Tokenize fees for existing token 0x123..."

"Create 1D time-wrappers and burn 50% of collected fees"

"Split fees: 40% burn, 30% LP, 30% to top 100 holders"
```
